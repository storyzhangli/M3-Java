## 一、概述

本迭代交付一套"一条命令可重复执行"的 RAG（Retrieval-Augmented Generation，检索增强生成）评测器与第一版基线：

1. 评测器（Java 21 独立程序 + Jackson 2.19.0，含 IN_MEMORY_LOCAL 内存降级后端）；
2. 20 问固定问题集 JSONL v1.0（四场景各 5，含 2 个注入用例，先冻结后评测）；
3. 第一版基线 baseline.csv + 汇总（按后端分目录、永久只读）；
4. 指标可测性说明 measurability-boundary.md；
5. 9 类失败标签规则 failure-label-rules.md；
6. 计算器自测证据、运行日志、状态文件与本文档等双文档。

核心诚实发现：当前运行时绑定的是**本地哈希词法 Embedding**（非神经语义模型），受控参数 topK=5/threshold=0.0 下检索排序正确（hitRate=1.0）但相似度普遍低于评估阈值 0.55，导致 PGVECTOR 离线基线 20 问全部受控拒答（误拒率 1.0）。**未调阈值美化**；该结论不得外推到神经 Embedding。

## 六、操作手册（可重复执行）

### 6.1 前置
- JDK21：`D:\SoftwareInstall\JDK\JDK21`；Jackson 2.19.0 三件套位于 `D:\SoftwareInstall\Apache\repository`。
- PGVECTOR 模式需应用启动：用户环境变量 `PG_VECTOR_PASSWORD` 注入会话后 `mvn -f D37\pom.xml -pl D37_RAG_ESAB spring-boot:run`（AI_MODE 默认 mock）。
- 语料入库（仅本迭代 3 个 documentId）：`pwsh -File docs\temp_docs\D37\index-corpus.ps1`。

### 6.2 一条命令评测
```powershell
pwsh -File docs\temp_docs\D37\run-evaluation.ps1 -BaseUrl "http://127.0.0.1:8080" -DatasetVersion "v1.0" -Rounds 3 -Warmup 3
```
脚本自动：编译（含 UrlSafetyPolicy 原文件）→ SelfTest（全 PASS 才继续）→ 正式评测。退出码：全 PASS=0 / 有 FAIL=1 / 仅 BLOCKED 或 NOT RUN=2。应用未启动时自动降级 IN_MEMORY_LOCAL。

### 6.3 复现性验证与基线冻结
```powershell
# 两次独立运行后逐字节 diff（质量投影排除耗时/时间戳/相似度浮点）
java -cp "classes;jackson jars" d37eval.Evaluator --diff <runA> <runB> --out consistency-diff.json
# diff 退出 0 才允许复制 run 产物到 baseline\v1.0\<backend>\ 并设只读
```

### 6.4 特殊夹具（基线冻结后执行，避免污染）
`special-fixtures.ps1`：CONFLICT 夹具（先 register 落 ACTIVE 行→同标题两片段"额定压力 0.8/1.2"→CONFLICT/EVIDENCE_CONFLICT）；生命周期 fail-closed 夹具（无 MySQL 行→NOT_FOUND→REFUSE/NO_EVIDENCE）。用后 DELETE 向量 + JDBC 清理登记行（FIXTURE_REMAINING=0）。
