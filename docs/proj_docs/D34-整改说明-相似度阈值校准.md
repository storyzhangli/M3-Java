# D34 整改说明：相似度阈值校准

> 整改类型：D34 验收安全整改（P1）
> 路径约定：本文统一使用相对路径，仓库根目录记为 `<仓库根>`（即 `M3-Java`），不出现本机绝对路径。
> 核心结论先行：**样本量不足以可靠标定生产阈值，保留生产默认 0.55 并显著标记“待校准”，不盲目改为 0.25。**

### 1.2 相似度与距离的方向核验

- pgvector 距离类型：`PgDistanceType.COSINE_DISTANCE`（余弦距离）。
- 换算关系：`similarity = 1.0 - distance`（见 `SimilarityMatchView`），真实日志中 `0.3394 + 0.6606 = 1.0` 可印证。
- 方向：相似度越接近 1 越相关；余弦距离越小越相关。
- 阈值口径：阈值是**相似度**（非距离），框架内部换算为距离边界 `1 - similarity`；评估服务比较式为 `similarity < threshold → 低相关`，方向正确，未把 distance 当 similarity。
- 触发规则：仅当**全部证据**相似度低于阈值（且非 null）才判定 `LOW_RELEVANCE`，单条低分不阻断其余证据。

## 三、误拒与错误放行统计

判定口径：单证据场景下，`相似度 < 阈值` 判低相关拒答，`相似度 >= 阈值` 通过该门。

### 3.1 生产阈值 0.55

- 表中 11 个分数全部 `< 0.55`，单证据场景**全部被判低相关**。
- 明确误拒：接地合法查询（0.3394）及所有主题相关证据被拒。
- 正确拒绝：无关样本 0.1794。
- 结论：在当前本地 Embedding 模型的余弦分数区间（约 0.18–0.42）下，0.55 会导致真实相关证据被误拒，存在**误拒风险**。真实测试之所以通过，是因为测试内联覆盖为 0.25，并非生产 0.55 本身合理。

### 3.2 测试阈值 0.25（仅测试，不进生产）

| 分组 | 分数 | 数量 | 判定是否符合预期 |
| ---- | ---- | ---- | ---------------- | -------- |
| 拒绝（`< 0.25`） | 0.1794、0.1850、0.2078、0.2410 | 4 | 无关/低相关正确拒绝；0.2410 为弱查询边界点 |
| 通过（`>= 0.25`） | 0.2805、0.3364、0.3385、0.3394、0.3446、0.3481、0.4150 | 7 | 接地合法 0.3394 正确通过 |

- 对两个明确锚点：接地合法通过、无关样本拒绝 → 当前小样本上 0 误拒、0 误放。
- 边界点：弱查询 0.2410 紧贴 0.25 下方，结论对阈值微小变动敏感。
- 安全说明：部分含攻击载荷（0.2805 及以上）能通过**相似度门**，这是预期行为——相似度门是“相关性门”而非唯一注入防线；注入由上下文不可信标记、Prompt 约束与生成后校验等多层安全共同拦截，真实测试已验证注入不被执行。

### 3.3 统计汇总

| 阈值 | 明确误拒 | 明确误放 | 说明 |
| ---- | -------- | -------- | ---- |
| 0.55（生产） | 接地合法证据被误拒 | 无 | 与当前模型分数区间不匹配，待校准 |
| 0.25（测试） | 小样本锚点 0 误拒 | 小样本锚点 0 误放 | 仅 3 文档、2 锚点，不能外推为生产值 |

## 四、阈值调整结论

1. **不修改生产默认值**：保留 `EvidenceAssessmentProperties.lowRelevanceSimilarityThreshold = 0.55`，不直接改为 0.25。
2. **理由**：
   - 仅 3 文档、11 探针、2 个明确正负锚点，样本量不足以支撑生产安全门调整；
   - 0.2410 边界点紧贴 0.25，阈值微小变动即改变结论，缺乏统计裕度；
   - 仅为让现有测试通过而降低生产阈值，会把测试夹具口径误当生产口径，违反“测试与生产不互相污染”。
3. **显著标记待校准**：生产 0.55 在当前模型分数区间存在已知误拒风险，列为正式待办，不得描述为已标定的合理值。

## 五、后续校准计划（不改变本次硬边界）

1. 基于真实语料构建标注集：按“明确相关/弱相关/无关/边界”分类，保证每类足够样本（远多于当前 2 个锚点）。
2. 在候选阈值网格上分别统计误拒率（FRR）与错误放行率（FAR），并结合注入拦截要求确定可接受的工作点。
3. 以明确目标（如目标误拒率上限）选定阈值，再修改生产默认值并保留评测证据；在证据充分前维持 0.55。
4. 校准期间继续依靠多层安全（不可信证据标记、Prompt、生成后校验），不把相似度门作为唯一防线。
