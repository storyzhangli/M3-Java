### 4.5 PowerShell 纪律（血泪清单，全程沿用）

- 一律 `-creplace`（`-replace` 大小写不敏感会吃掉小写 d43→污染表名，run1 轮实证）。
- 变量/函数名大小写不敏感（`$P` 覆盖 `$p`；`Cli` 撞 Clear-Item 别名）。
- `@($null).Count` **=1**——判空必须 `$null -ne $data`（demo 首轮 ERR 根因）。
- `Join-Path` 必须双参；`Get-ChildItem -Filter` 不收数组（用 -Include）。
- eval 长脚本禁 `Select -First` 截管道，Tee 全量落盘。
- 路径早期展开陷阱：矩阵脚本参数用 PLACEHOLDER 循环内替换+活取（TID-LIVE/SIDA-LIVE）。
