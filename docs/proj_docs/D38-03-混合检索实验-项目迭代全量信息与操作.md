## 三、实现清单

**应用侧 18 个新 Java 源**（`com.zl.d38.hybrid`，全部受 `@ConditionalOnProperty(prefix="d38.hybrid", name="enabled", havingValue="true")` 控制，默认关闭）：配置绑定、UTF-8 分词器、倒排索引（term→posting 链，tf/docLen 内联）、BM25 打分（`bm25Score` 静态纯函数化供评测直调）、RRF 融合（`RrfFusionService.fuse` 静态化）、候选合并、hybrid 检索/ask 控制器与服务、索引管理端点。`application.yml` 净增 18 行（开关与参数），**未改任何既有行**。

**评测侧**（`docs/temp_docs/D38/hybrid_evaluator/src/hybrideval/`）：
- `EnvProbe`：三态探测 DUAL_STRATEGIES / BLOCKED / UNREACHABLE，ProbeInput 8 布尔；无内存兜底、无单轨降级（降级=熔断）。
- `Backends`：仅 HttpBackend；`searchHybrid` 的 Hit.similarity 槽承载 RRF 融合分，向量原值/hitSource/matchedTerms 保留在 `extra.rawMatches` 由 Evaluator 合并。
- `Evaluator`：ABAB 交错（奇数轮 PURE→HYBRID、偶数轮反序，消除时段偏置）；记录键 `qid|strategy`；qualityProjection 含 strategy+逐命中 hitSource/vectorRank/keywordRank（整型入键，浮点全排除）；`--diff`（C11）、`--compare`（分发到 Compare）。
- `Compare`：P6 公式全现算（不读缓存结论），输出 `comparison-report.json`、`metrics-matrix.csv`、`cases.md`、`decision.txt`。
- `SelfTest`：84 检查，含 hybridMath 14 项——直接 import 应用真实类（`RrfFusionService.fuse`、`InvertedIndex.idf`、`KeywordSearchService.bm25Score`）做手算夹具对拍，杜绝"评测自说自话"。
