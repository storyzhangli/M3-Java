# D36 实验设计调整记录（阈值地板发现）

## 现象（真实冒烟检索，Boot1/G0 索引）

Q001 在 threshold=0 下 Top-5 真实 similarity：0.2499 / 0.1793 / 0.1348 / 0.0875 / 0.0279。
**最高分 0.2499 < 指定阈值 0.25**：G0（th=0.25）与 G4（th=0.35）在该问题上返回 0 条。

## 根因

本地哈希 Embedding（local-hashing-embedding/local-v1）的 COSINE 相似度分布整体偏低（已知偏差），
指定受控基准的 0.25/0.35 阈值高于其有效分数区间，导致"阈值过滤一切"的退化矩阵——
切分/Top-K 变量在 G1/G2/G3 中将不可观测（全为空检索）。

## 决策（保持单变量控制，不修改冻结数据集）

1. **指定矩阵照跑并如实记录**：G0(200/20/5/0.25)、G1(500/20/5/0.25)、G2(200/50/5/0.25)、G3(200/20/10/0.25)、G4(200/20/5/0.35)。空检索按 N/A + EMPTY_RETRIEVAL 记录，不伪造。
2. **新增阈值 0 平行矩阵**（第二受控基准 B0，仅阈值不同于 G0）：
   - B0 = 200/20/5/**0**（平行基准）
   - B1 = 500/20/5/0（相对 B0 只改 chunkSize）
   - B2 = 200/50/5/0（相对 B0 只改 overlap）
   - B3 = 200/20/10/0（相对 B0 只改 Top-K）
3. 阈值影响由 G0 vs B0（0→0.25）与 G4 vs G0（0.25→0.35）两组对照共同刻画。
4. 该调整属于实验设计对真实分数语义的响应，问题集/文档集/标注/模型/度量均未改动。

## 对结论的影响

- "哪个参数影响最大"的预期答案方向：阈值（地板效应）；切分/Top-K 的真实效应以 B 矩阵为准。
- 所有结论仅适用于本地哈希 Embedding + 冻结语料，不外推神经 Embedding。
