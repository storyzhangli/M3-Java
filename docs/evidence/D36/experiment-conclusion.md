## 2. 参数影响结论（按影响幅度排序）

1. **阈值影响最大（Recall 与精度双向）**：0→0.25 使 Recall 1.0→0.7778（Q001/Q005 被误过滤，Q001 最高分 0.2499 仅差 0.0001）；0.25→0.35 进一步跌到 0.4444，空检索 9→18。同时阈值把 Precision 从 0.2383 拉到 0.9286/1.0，并消除无答案误检（B 矩阵 Q010 每组 3 次误检，G 矩阵 0 次）。**本地哈希 Embedding 分数区间（本语料 B0 组 Top1 实测 0.2144–0.5015）与"通用阈值 0.25"根本不匹配。**
2. **chunkSize 次之（Recall 负向、Precision 正向）**：200→500 使 G 矩阵 Recall 0.7778→0.6667（Q004 伺服过载信号被整篇混合文本稀释，新增漏召回）；B 矩阵 Precision 0.2383→0.3333（返回 chunk 总数 5→3，单 chunk 覆盖更多证据）。大 chunk 省索引但伤细粒度召回。
3. **overlap 影响微弱**：20→50 在本语料未改变任何问题的命中/精度（G2≡G0；B2 Precision 0.2383→0.2783 仅因边界移动改变个别 chunk 的相关判定）。语料片段短（60–75 字符），边界截断风险本就低。
4. **Top-K 影响为零（本语料）**：5→10 指标完全一致——全库仅 5 个 chunk（G0/G2）或 3 个（G1），K=10 超过库存，边际收益为 0。耗时未见上升（库太小）。
5. **耗时**：全部组平均 1.7–2.7ms（Embedding 段 0.03–0.22ms，检索段 1.6–2.5ms），检索段占绝对主导；组间差异小于运行抖动，**本规模不足以得出参数-性能结论**。

## 3. 推荐组合与适用范围

- 本教学语料 + 本地哈希 Embedding：**200/20/TopK5/threshold≈0.22–0.24**。数据依据：可回答问题 Top1 最低 0.2408（Q005），无答案 Q010 Top1=0.2144；阈值取 (0.2144, 0.2408] 区间可同时保住全部 9 个可回答问题的召回并过滤 Q010 误检。0.25 已被证明过高（恰好误杀 Q001=0.2499、Q005=0.2408）。
- 该推荐**仅适用于**冻结的模型/语料/问题集/实现版本；换神经 Embedding 后分数分布完全不同，阈值必须重标定。

## 4. 错误案例（详见 error-cases.csv，共 111 条记录）

- EMPTY_RETRIEVAL：G0/G2/G3 各 9（Q001/Q005/Q010×3 轮）、G1 12（+Q004）、G4 18（Q001/Q002/Q004/Q005/Q008/Q010）。
- MISS_RECALL：与空检索同源（阈值误过滤 + 大 chunk 稀释）。
- UNANSWERABLE_FALSE_POSITIVE：B 矩阵各 3（Q010 激光切割机问题在 th=0 下必返回内容）。
- IRRELEVANT_TOP1：0 条——可回答问题首位结果均相关（小库排序质量尚可）。
- 跨轮一致性：所有错误计数均为 3 的倍数，3 轮结果完全一致（确定性检索）。

## 5. 已知偏差与不能得出的结论

1. 本地哈希 Embedding 非神经语义模型，COSINE 分数不可解释为语义正确概率；阈值结论不可外推。
2. 语料仅 3 文档 8 片段、问题 10 个：Top-K/overlap/耗时结论受规模限制，不能推广到生产库。
3. 未测：神经 Embedding、Reranker、混合检索、大库性能、并发负载。
4. 本次为检索层实验，未涉及生成质量；Recall 口径与 D35 Evidence Assessment 相关性判断无关。
