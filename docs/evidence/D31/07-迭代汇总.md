## 五、关键工程结论

1. 框架原生 Upsert（ON CONFLICT）+ 稳定 UUID 已保证 DB 级幂等，MySQL 唯一约束兜底并发；
2. 「先写后切 + 旧版确认后清理」避免更新时全丢；
3. 本轮发现的主键回写缺陷证明：只验一次写入会漏掉状态机静默失效，必须验重复/失败/更新/删除；
4. 跨系统一致性靠核对补偿收敛，不引入分布式事务与第二套向量库。
