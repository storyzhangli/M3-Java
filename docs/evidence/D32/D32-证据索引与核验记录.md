## 5. 来源信息与分数能力核验

- 来源字段全部来自真实 metadata：documentId、title、version、strategy、chunkIndex；chunkId 为 D31 UUID v5 稳定 ID。
- 分数语义（字节码取证 `rowmapper.txt`）：
  - distance：`getFloat("distance")`，PG `<=>` 余弦距离，越小越相似；
  - similarity：`Document.score = 1 - distance`，越接近 1 越相似；
  - 恒满足 `similarity = 1 - distance`，不把 distance 当 similarity，不手工归一化或编造。

## 6. 元数据/版本过滤真实下推（详见同目录 jsonpath 实证）

真实渲染（ConvProbe 输出）：

```text
metadata::jsonb @@ '$."documentId" == "d32it-air"'::jsonpath
metadata::jsonb @@ '$."version" == 1'::jsonpath
metadata::jsonb @@ '$."documentId" == "d32it-air" && $."version" == 1'::jsonpath
metadata::jsonb @@ '($."chunkIndex" == 0 || $."chunkIndex" == 1 || $."chunkIndex" == 2)'::jsonpath
```

- 过滤经 `::jsonb` + `@@` jsonpath 在 PG WHERE 内执行，属真实下推，非内存过滤。
- `==`、`&&`、`||` 为 jsonpath 内部运算符，合法；裸 SQL `SELECT 1 == 1` 报错不适用此语境。
