# D30 证据 06：维度一致性核验（256 唯一决策落地）

> 取证方式：读取 `EmbeddingProperties` 源码、`application.yml` 配置，并以真实测试断言验证。

## 一、EmbeddingProperties 真实默认值

来源：`com.zl.d30.document.embedding.config.EmbeddingProperties`

| 字段 | 真实默认值 |
| --- | --- |
| provider | `local` |
| model | `local-hashing-embedding` |
| modelVersion | `local-v1` |
| dimensions | **256** |
| maxInputLength | 8192（UTF-16 字符，非 Token） |
| distanceMetric | `COSINE` |
| maxAttempts | 3 |
| initialBackoffMs | 200 |
| backoffMultiplier | 2.0 |
| maxBackoffMs | 5000 |

## 二、application.yml 显式 embedding 块（决策自文档化）

```yaml
app:
  ai:
    embedding:
      enabled: ${EMBEDDING_ENABLED:true}
      provider: ${EMBEDDING_PROVIDER:local}
      model: ${EMBEDDING_MODEL:local-hashing-embedding}
      model-version: ${EMBEDDING_MODEL_VERSION:local-v1}
      dimensions: ${EMBEDDING_DIMENSIONS:256}
      max-input-length: ${EMBEDDING_MAX_INPUT_LENGTH:8192}
      distance-metric: ${EMBEDDING_DISTANCE:COSINE}
```

显式写出 `dimensions: 256`，使维度决策在配置中可直接读取，而非依赖隐式默认；所有字段均支持环境变量覆盖。

## 三、模型维度与配置维度的真实对齐

`PgVectorStoreConfiguration` 同时读取两个来源并断言：

```java
int dimensions = embeddingProperties.getDimensions();      // 配置 = 256
int modelDimensions = embeddingModel.dimensions();         // 模型真实输出 = 256
if (modelDimensions != dimensions) {
    throw new IllegalStateException("EmbeddingModel 维度与配置维度不一致……");
}
```

| 来源 | 真实值 |
| --- | --- |
| `EmbeddingModel.dimensions()` | 256 |
| `EmbeddingProperties.dimensions` | 256 |
| 正式表 `vector(N)` | vector(256)（见证据 07） |

三者一致，且不一致时启动即抛异常，杜绝「只改库不同步模型」。

## 四、真实测试覆盖

- `PgVectorStoreConfigurationTest.vectorStoreRejectsDimensionMismatch`：
  用 `dimensions()=384` 的模型对接 256 配置，**断言抛出 IllegalStateException** 且消息含「维度不一致」。
- `PgVectorStoreConfigurationTest.vectorStoreBuiltWithMatchingDimensions`：
  256 对 256 时正常装配，距离类型为 `COSINE_DISTANCE`。

## 五、长度口径澄清

- 输入长度单位为 **UTF-16 code unit**（`String.length/substring` 口径），**字符数 ≠ Token**；
- 本轮不引入 Tokenizer、不宣称 Token；Embedding 输出 `float[]`，默认 L2 归一化，距离默认 COSINE。

## 六、结论

维度 256 已在「属性默认值、显式配置、模型真实输出、正式表 DDL、真实测试」五个层面一致落地，
并由启动期断言与单测双重保证 fail-closed；字符数与 Token 的口径在代码与配置中严格区分。
