## 三、真实集成测试覆盖点（6 个，均真实执行非跳过）

1. `contextHasExactlyOneVectorStoreBean`：容器内仅 1 个 VectorStore，名为 `pgVectorStore`，自动配置回退；
2. `embeddingColumnIsVector384`：catalog 回读 embedding 列类型为 `vector(384)`；
3. `realWriteIncreasesCount`：真实写入 3 条，count 由 N 增长到 N+3；
4. `similaritySearchRanksLexicallyRelatedFirst`：真实余弦检索，相关文档排第一且分数降序、落在 [0,1]；
5. `wrongDimensionInsertIsRejected`：错误维度写入抛 DataAccessException，fail-closed；
6. `hnswIndexExistsOnVectorTable`：正式表存在 1 个 HNSW 索引。

## 四、门控机制（不拿跳过冒充通过）

- 注解 `@EnabledIfPgVector` + `PgVectorReachableCondition`：以 1 秒 TCP 探测判断数据库是否可达；
- 本次执行数据库可达，集成测试**真实运行并断言**，未被跳过；
- 若在无数据库环境，测试会被明确标记禁用并给出原因，而非产生误导性结果。

## 五、配置加固后的复测（真实）

为满足「真实密码不写入 Git」的硬约束，`application.yml` 中密码默认值改为空：
`password: ${PGVECTOR_DB_PASSWORD:}`，真实密码仅由环境变量注入。

随后显式设置 `PGVECTOR_DB_PASSWORD` 后重新执行全量 `mvn clean test`
（日志：`logs/D30/09-mvn-clean-test-envvar.log`），结果仍为：

```text
Tests run: 287, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

证明环境变量注入路径下集成测试真实连接、真实写入、真实检索全部通过；未设置环境变量时，
`PgVectorStoreProperties.validate()` 会因密码空白 fail-fast，不静默启动。
