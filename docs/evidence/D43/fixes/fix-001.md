# FIX-D43-001 夹具 manifest 迁移断裂（阻断级，已修复）

## 1. 根因

- **现象**：HEAD `c47be85` 上 C01 继承基线 **99/100**，唯一 FAIL=
  `PdfTableFixtureTruthTest.fixtureManifestIntegrity`
  （AssertionFailedError：夹具缺失: d42-anomaly-crosspage.pdf，BUILD FAILURE，
  证据 `probe\c01-mvn-inherited.log`）。
- **定位**（逐文件实证）：骨架迁移 d42→d43 时——
  1. 9 个夹具文件已改名 `d43-*` 且内容与 d42 版**逐哈希 SAME**（PDF/MD 内容不含文件名，
     对照表见本文件 §4 修复输入）；
  2. `fixture-truth.json` 已重写为 d43 键（9 条目 file 字段全部 d43-*）；
  3. 测试代码 `DIR`/`tablesOf(...)` 全部 d43 引用；
  4. **唯独 `FIXTURE-SHA256.txt` manifest 原样照搬 d42 版未重新生成**——9 行文件名旧前缀
     （测试按 manifest 键读资源 → d42-* 不存在 → 夹具缺失 FAIL），第 10 行
     fixture-truth.json 哈希仍是 d42 旧版内容（truth 已重写 → 哈希必然 DIFF，
     即使文件名字段修好也会在第二断言失败）。
- **根因判定**：迁移流程遗漏（资产未闭环重生成），非解析/权限/数据缺陷。
  manifest 与夹具本体自相矛盾=测试资产链路断裂。
