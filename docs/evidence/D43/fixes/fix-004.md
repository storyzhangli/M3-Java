# FIX-D43-004 indexChunks 同版本重建 PG 向量残留致 COUNT_MISMATCH（阻断级，已修复并验证）

## 1. 根因

- **现象**：lifecycle run2 L4 格：对已入库文档（PIPE-001）以**同 documentId+version** 重放
  `POST /vector-index/index` → PG 本版本行数就地覆盖后计数与 chunk 表口径错位 →
  一致性门禁 **COUNT_MISMATCH** 阻断，重建通道断裂（资产修复/重放场景必现）。
- **定位**：`DocumentVectorIndexService.indexChunks` 假定"先删后建"总由调用方完成；
  就地覆盖写入不清理本版本旧向量行，`countPgForVersion` 对不上 `processed`。
- **根因判定**：数据一致性域阻断（H1 必修；影响解析→入库主链幂等性）。
